## 开发目的
本软件旨在利用人工智能技术，为用户提供高效、便捷的考试题目自动生成服务。用户上传学习资料后，系统可自动解析文档内容，调用大语言模型生成多种类型的专业考题，支持练习模式与错题回顾，帮助学习者巩固知识、提高备考效率。适用于教师出题、学生自测、企业培训等场景。

## 面向领域 / 行业
教育 / 在线教育

## 软件的主要功能

1. 多格式文档智能解析：支持用户上传 PDF、DOCX、XLSX、PPTX、EPUB、ODT、TXT、CSV、HTML 等九种主流格式的学习资料文件，系统自动识别文件类型并提取其中的文本内容，包括段落文字、表格数据、标题层级等结构化信息，并对提取结果进行智能清洗和排版还原，为后续出题提供高质量的文本素材。
2. AI 智能出题引擎：基于用户上传并解析后的学习资料文本，调用兼容 OpenAI Chat Completions API 格式的大语言模型服务（如 OpenAI GPT 系列、DeepSeek、通义千问、智谱 GLM 等），自动生成符合教育测量标准的专业考题。支持的题型包括单选题、多选题、判断题、填空题和简答题共五种。用户可自定义题目数量、难度等级（简单、中等、困难）和题目语言（中文、英文）。对于内容较多的文档，系统自动将文本分块并按比例分配题目数量，分批次调用 AI 生成后合并结果。
3. 题库管理与数据导出：每次 AI 生成的题目集合自动保存为独立题库，支持按题库名称重命名、查看、浏览和删除管理。支持将题库导出为 XLSX（Microsoft Excel 格式）和 CSV（逗号分隔值）两种格式文件，导出内容包含题号、题型、题干、选项、正确答案和解析等完整信息，便于用户打印试卷、分发给学生或导入其他教学管理系统使用。
4. 在线练习与刷题系统：内置功能完善的在线答题模块，用户可选择题库进入练习。提供顺序练习（按题目原始顺序依次作答）和随机练习（随机排列题目顺序）两种练习模式。答题过程中系统即时给出正确或错误判定，并展示完整答案解析，帮助用户在练习中同步巩固知识点。完成所有题目后显示正确率、答题统计等详细练习结果。
5. 智能错题追踪与管理：系统在用户练习过程中自动记录答错的题目，追踪每道错题的累计错误次数、连续正确次数和最近错误时间。提供错题本集中查看功能，支持按错误次数、错误时间等多种方式排序和筛选错题。支持错题专项复习练习，当用户对某道错题连续答对达到设定次数后自动将其从错题本移除，实现智能化的薄弱知识点攻克。
6. AI 配置加密存储：在桌面端和移动端应用中，用户的 AI API 密钥等敏感配置信息采用 AES-256-GCM 对称加密算法加密后安全存储在操作系统标准配置目录中，加密密钥通过 PBKDF2 算法从设备信息派生，有效防止密钥明文泄露，保障用户隐私安全。
7. 多平台覆盖：提供桌面端原生应用（支持 macOS、Windows、Linux）、移动端应用（支持 iOS、Android）、Web 浏览器网页版、Docker 容器化自托管部署以及 Cloudflare Workers 无服务器边缘计算部署共五种使用方式，用户可根据自身需求和使用场景灵活选择。各平台版本功能保持一致，数据完全存储于用户本地设备。
8. 多语言界面支持：软件界面完整支持中文（简体）和英文两种语言，用户可在设置页面随时切换，切换后即时生效无需重启。界面中所有按钮标签、菜单项、提示信息和错误消息均提供完整的中英文双语文本，满足不同语言背景用户的使用需求。

技术架构特点：

1. 前端技术：采用 Vue 3 + Vite + TypeScript + Tailwind CSS 构建现代化单页应用，使用 Pinia 进行状态管理，Vue Router 实现前端路由。界面采用 Material You 设计语言，提供优秀的用户体验。

2. 后端技术：核心逻辑采用 Rust 语言编写，使用 Axum 框架构建高性能 Web 服务。Rust 代码同时编译为 Tauri 桌面/移动应用后端和独立 Web 服务器，实现代码复用。

3. 无服务器部署：支持部署到 Cloudflare Workers 平台，基于 Hono 框架构建边缘计算服务，实现低延迟的全球访问。

4. AI 集成：兼容所有 OpenAI API 格式的大语言模型接口，支持自定义 API 端点和模型选择，具备灵活的多模型切换能力。

5. 多格式解析：服务端和前端均实现多种文档格式的解析引擎，支持 PDF、Office 文档、电子书、纯文本等格式的无缝处理。

6. 安全加密：采用 AES-256-GCM 加密算法对用户敏感配置信息进行加密存储，确保 API 密钥等数据安全。

7. 跨平台：基于 Tauri v2 框架实现桌面端（macOS / Windows / Linux）和移动端（iOS / Android）原生应用。
