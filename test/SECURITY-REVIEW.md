# Exameow CF 中转服务 风险清单与缓解方案

日期：2026-07-25
范围：`exam.superagentparty.com`(Cloudflare Worker + D1)，重点是无鉴权的 `/api/exam/*` 与 AI 端点。
结论速览：**无 XSS / SQL 注入 / 密钥泄漏风险**（已核查）；主要风险是**内容滥用**与**资源刷量**，均有低成本缓解手段。

---

## 高危风险

### H1. 内容滥用：任何人可发布任意文本并公开分发
- **描述**:`POST /api/exam/publish` 无鉴权，可上传 500 题 / 5MB 任意 JSON 文本，获得 6 位码和公开链接，可被用于分发违规内容（盗版资料、违法信息、钓鱼文本等），数据保留 7 天。
- **影响**：域名被举报/封禁、运营者法律责任（内容平台审核义务）、CF 账号被 ToS 处置。
- **缓解方案**:
  1. **(运营，必做）** 在 CF Dashboard 开启 **Bot Fight Mode + WAF 免费托管规则集**，挡掉批量机器发布。
  2. **(代码，建议）** 增加管理员下架通道：Worker 加 `ADMIN_TOKEN` secret,`DELETE /api/exam/admin/{code}` 凭该 token 强制删除任意考试——被举报时可秒级下架。
  3. **(代码，建议）** 发布接口加每 IP 每日限额（如 20 场/天），用 Workers KV 计数（免费硬墙，不误伤正常教师）。
  4. **(运营）** README 与隐私政策声明"用户生成内容与本项目无关"（已加免责声明）；收到举报邮件优先处理。
  5. **(可选，重）** 接入 CF AI 内容审核（免费额度内）对发布文本做违规分类，命中则拒绝——成本较高，日活低时可不做。

### H2. AI 端点刷量：`/api/generate` / `api/answer` / `api/judge` 免费算力被薅
- **描述**：演示站的 CF Workers AI 是免费额度（按神经元/天），无鉴权无限制，脚本可 7×24 刷空，导致正常用户全天 503。CORS `origin: *` 还允许第三方网站访客浏览器被动调用。
- **影响**：服务不可用（不扣费——CF 免费层是硬墙）。
- **缓解方案**:
  1. **(运营，必做）** CF **Rate Limiting**（免费版含 1 条规则）：对 `/api/generate`、`/api/answer`、`/api/judge` 限制每 IP 10 次/分钟。
  2. **(代码）** 在 Worker 内对 AI 端点加每 IP 每日次数上限（KV 计数），超限返回 429 并提示"请配置自己的 API 或明日再来"。
  3. **(代码）** 校验 `Origin`/`Referer`：浏览器跨域请求（非同源）对 AI 端点直接拒绝（APP 的 fetch 不带 Origin，不受影响）。

### H3. D1 写入刷量导致服务降级
- **描述**：脚本循环发布/交卷可打满 D1 每日 10 万行写入硬墙，当天考试功能全挂（不扣费）。
- **缓解方案**:
  1. 同 H1-3 的每 IP 发布限额（发布 1 行/场）+ 交卷接口每 IP 每分钟限额（KV 计数）。
  2. Rate Limiting 规则覆盖 `/api/exam/*`（每 IP 60 次/分钟宽松档）。

## 中危风险

### M1. 6 位码枚举（部分缓解：举报与暂停机制已上线）
- **描述**：码空间约 8.9 亿，暴力枚举不现实，但配合 Rate Limiting 缺失时可批量探测；命中即可看到题目（无答案）并交卷灌水。
- **缓解**：H3 的速率限制天然覆盖；无需缩短码长。成绩页有管理 token 保护，不受影响。

### M2. 管理 token 泄露面
- **描述**:manageUrl 含明文 token，存于 localStorage、可能出现在浏览器历史/分享截图中；泄露者可查看全部成绩（不可改删？——可删除，因 DELETE 也用同一 token)。
- **缓解**:
  1. （文档）提示教师管理链接保密（发布成功页已有文案）。
  2. （可选，代码）成绩与删除改用"教师密码"二次确认，增加泄露后的缓冲。当前风险可接受。

### M3. 恶意构造输入（畸形 JSON / 超大 payload / Unicode 炸弹）
- **现状**：已有 5MB、500 题、窗口≤7 天校验；非字符串字段已加固。
- **缓解**:Worker 免费层请求体超限自然报错；无需额外处理。

### M4. CI/CD 供应链
- **描述**:release 流水线持有 `DOCKERHUB_TOKEN`、Tauri 签名私钥等 secrets;tag 触发。
- **缓解**：确认仓库只有你可推 tag(Repo → Settings → Branches 保护 main + 限制 tag 创建权限）；定期轮换 DOCKERHUB_TOKEN。

## 低危风险（已核查，无需动作）

| 项 | 结论 |
|---|---|
| XSS | 前端全部 `{{ }}` 插值渲染（Vue 默认转义），无 `v-html`，题干/作答原样文本展示 ✅ |
| SQL 注入 | D1 全部 `.bind()` 参数化 ✅ |
| 密钥泄漏 | `CF_ACCOUNT_ID` 非敏感；updater pubkey 为公钥；无私钥入仓 ✅ |
| DDoS 成本 | Worker/D1 免费层均为硬墙，超额报错不扣费，最多服务降级 ✅ |
| 判分作弊 | 答案取题阶段不下发、服务端判分；学生可交白卷看答案后换名重考（产品层已知取舍，README 已提示） |
